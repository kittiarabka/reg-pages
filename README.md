# Reg Pages

Небольшой pet-проект с адаптивными страницами регистрации и авторизации.

## О проекте

Проект представляет собой набор frontend-страниц для входа и регистрации пользователя.  
Основная цель — практика HTML/CSS, верстки форм, работы с UI-состояниями и аккуратной структурой проекта.

## Стек

- HTML5
- CSS3
- Flexbox
- Адаптивная верстка
- Семантическая разметка
- Работа с формами
- Организация CSS-файлов

## Что реализовано

- Страница регистрации
- Страница авторизации
- Поля для ввода данных пользователя
- Кнопки отправки формы
- Навигация между страницами входа и регистрации
- Стилизация форм
- Адаптивный интерфейс
- Базовая структура frontend-проекта
